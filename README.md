# Humanizer KR v0.1 — OMP · AGY · Codex · Claude

**문서를 가능하면 더 짧게 만드는** 한국어 공통 Agent Skill. 중복·장황한 설명을 줄이되 핵심 정보·수치·조건은 유지합니다. DeepSeek-V4.1-Flash, Claude Opus 5.5, Gemini 4 Argon을 주요 평가 대상으로 설계했습니다. 해당 모델에서 실제 품질 검증을 완료했다는 뜻은 아닙니다.

[참고·라이선스](NOTICE.md) · [스킬 원문](skills/humanizer-kr/SKILL.md) · [패턴 가이드](skills/humanizer-kr/references/patterns.md)

## 설치

저장소를 내려받은 뒤 프로젝트 루트에서 아래 명령 하나만 실행하세요.

```bash
bash install.sh
```

OMP, **AGY CLI**, Codex, Claude Code에 모두 설치합니다. 다시 실행하면 변경된 스킬을 백업 없이 갱신합니다. 예전 설치 스크립트가 생성한 `humanizer-kr.bak.날짜` 폴더도 스킬 이름을 확인한 뒤 자동 정리합니다. AGY IDE는 설치 대상이 아닙니다.

## 사용

**문서 수정 요청의 기본값은 간결하게 줄이기**입니다. 단순한 단어 교체뿐 아니라 문장·문단·구조의 중복도 줄입니다. 별도로 '짧게'라고 요청할 필요는 없습니다.

- OMP: `/skill:humanizer-kr 중복된 내용과 군더더기를 빼고 짧게 다듬어 줘: ...`
- AGY CLI: `/humanizer-kr 같은 말 반복하지 말고 짧게 답해 줘: ...`
- Codex: `$humanizer-kr 이 Markdown 문서에서 반복 설명을 줄이고 핵심만 남겨 줘`
- Claude Code: `/humanizer-kr 다음 이메일을 자연스럽게 다듬어 줘: ...`
- 자연어 요청: `humanizer-kr 스킬을 사용해 같은 말은 한 번만 하고, 숫자·조건은 유지해 줘.`

스킬은 **요청 시 선택되는 편집 워크플로**입니다. 모든 답변에 자동 적용하는 전역 정책은 아닙니다. 항상 적용하려면 아래의 선택적 짧은 지침을 각 에이전트의 상위 컨텍스트 파일에 추가하되, 기술 출력의 정확성이 더 중요할 때는 적용하지 마세요.

```
한국어 답변은 필요한 정보만 짧게 전달한다. 표현이 달라도 같은 주장은 한 번만 말하고, 불필요한 서론·재요약·배경 설명은 쓰지 않는다.
숫자, 불확실성, 전문용어, 코드, 조건은 정확히 보존한다.
사용자가 특정 글을 다듬어 달라고 요청할 때에만 humanizer-kr 스킬을 적용한다.
```

## 우선 적용 원칙

1. 같은 의미를 말만 바꿔 반복했다면 한 번만 남깁니다.
2. 질문에 바로 답하고, 본론 전에 안내하거나 끝에서 다시 요약하지 않습니다.
3. 내용을 유지하면서 줄일 수 있으면 더 짧은 문서를 선택합니다. 목표 감축률은 강제하지 않으며, 다른 근거·조건·예외·수치는 생략하지 않습니다.

이 스킬은 **호출 시 적용**됩니다. 평소의 모든 답변을 짧게 하려면 위의 짧은 지침을 에이전트의 상위 지침 파일에 별도로 설정해야 합니다. `bash install.sh`가 기존 상위 지침을 자동으로 변경하지는 않습니다.

## 감사 검사 (선택)

```bash
python3 skills/humanizer-kr/scripts/audit.py --input original.md --output rewritten.md
python3 skills/humanizer-kr/scripts/audit.py --input original.md --output rewritten.md --json
python3 -m unittest discover -s tests -v
```

검사는 숫자·코드·URL·템플릿 보존을 확인하며, 표현상 주의 신호의 전후 개수를 제시합니다. 실제 모델을 호출하거나 글을 자동으로 다듬지는 않습니다. 의미 보존이나 자연스러움을 자동 판별하지 않습니다. 코드 0은 검사 항목 통과, 코드 2는 리터럴 위반입니다.

## 아키텍처

```mermaid
flowchart LR
 A[한국어 원문/초안] --> B[핵심 정보 확인]
 B --> C[의미 중복 제거]
```

공통 `SKILL.md`는 하나이고, 4개 런타임의 발견 경로에 복사하거나 심링크합니다. 런타임별 명령 호출 방식만 다르고 핵심 규칙과 평가 항목은 같습니다.

## 후속 작업

1. 3개 모델에 `examples/fixtures.jsonl`을 동일하게 입력하고 중복 제거·간결함·의미 보존·문체 유지 기준으로 사람이 평가.
2. 실제 실패 사례에서 한국어 규칙을 보강. 무작정 규칙을 100개 이상 늘리기보다 정밀도 우선.
3. 필요한 경우 청킹, API 기반 배치 평가, 회귀 테스트 자동화 추가.

- 복사/설치 로직과 단위 테스트만 이 패키지 안에서 검증합니다. OMP·AGY·Codex·Claude 실행 환경에서의 실제 스킬 로딩·글 다듬기 품질은 미검증입니다.
