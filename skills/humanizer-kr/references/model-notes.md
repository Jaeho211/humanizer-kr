# 모델별 적응 가이드 (실측 전 가설, 기본 미적용)

지원 대상: DeepSeek-V4.1-Flash / Claude Opus 5.5 / Gemini 4 Argon.

모두 같은 SKILL.md와 보존 계약을 사용한다. 아래는 각 모델에서 검증할 *실험 항목*이며, 결함이 실측됐다는 주장이 아니다.

1. DeepSeek-V4.1-Flash: 긴 규칙집을 모두 읽지 않아도 core 계약을 따르는지, 존대 유지/불확실성 유지/조건 보존을 검사한다.
2. Claude Opus 5.5: 자연스러움 개선 과정에서 원문의 강조·논리 관계까지 바꾸지 않는지, 최소 수정 요청을 지키는지 검사한다.
3. Gemini 4 Argon: 글을 과도하게 줄이거나 자동 목록화하지 않는지, 한국어 높임말·기술 명칭을 유지하는지 검사한다.

## 평가 기준

- 동일한 입력/지시로 3개 모델 평가. 최소 3회 반복해서 재현성 확인.
- **기계 검증:** 숫자·링크·인라인 코드·코드 블록 보존 여부.
- **사람 평가:** (1) 자연스러움, (2) 의미 보존, (3) 장르 일치, (4) 원문 불필요 수정 여부를 1~5점으로 따로 평가.
- 자연스러움 점수가 높아도 의미·조건을 훼손한 출력은 불합격.
- 모델별 예외 규칙은 반복 실패가 확인됐을 때만 추가. 설명할 수 없는 수치형 점수(예: 'AI 탐지 확률')는 만들지 않는다.
