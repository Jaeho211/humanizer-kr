# 장르별 자연스러움 기준

| 장르 | 우선 목표 | 피할 일 |
|---|---|---|
| 업무용 메시지 | 용건·결정·요청이 빠르게 드러나기 | 불필요한 의례적 인사, 근거 없는 확신 |
| 기술 문서 | 조건·행동·결과·제약 명확히 | 전문어를 억지로 바꾸기, 판단 조건 누락 |
| 보고서 | 사실/해석/권고 구분 | 문어체를 구어체로 바꾸기 |
| 이메일 | 수신인 관계와 존대 적절히 | 매 문단 자동 소제목·이모지 |
| 블로그/칼럼 | 문장 호흡 다양화, 실제 필자 목소리 유지 | 없는 비유·경험·사례 꾸며내기 |
| 대화형 응답 | 질문에 먼저 답하기, 문맥 반복 줄이기 | 불필요한 프리앰블, 상투적 마무리 |

## 스타일 선택

기본: **원문 문체 유지**. 사용자가 명시하면 `간결`, `친근`, `격식`, `기술적`, `최소 수정`을 추가 스타일로 적용한다. 사용자의 스타일 지시가 보존 계약보다 우선하지는 않는다.

## 형식 예외

원문의 목록이 정확한 요구사항, 순서, 검사 항목 등을 나타내면 목록을 유지한다. 표·코드·명령어는 문체로 인한 편집에서 제외한다. 이모지와 강조는 과다할 때만 줄인다.
